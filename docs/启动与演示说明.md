## 一、启动方式

### 方式 1：双击启动

进入项目目录：

```text
<项目根目录>
```

双击：

```text
start_api.bat
```

脚本会自动执行：

```text
安装/检查依赖 -> 生成测试数据 -> 启动 FastAPI -> 打开系统页面
```

### 方式 2：命令行启动

在 PowerShell 中执行：

```powershell
cd "<项目根目录>"

# 1. 设置认证密钥（必填，至少 16 位随机字符串；代码不提供默认值）
$env:TEMPERATURE_AUTH_SECRET = python -c "import secrets; print(secrets.token_hex(32))"

# 2. 安装依赖、生成演示数据并启动
python -m pip install -r requirements.txt
python scripts\seed_data.py
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8008
```

方式 1 双击 `start_api.bat` 时，脚本会在未设置密钥的情况下自动生成一个仅限本机演示的随机密钥，无需手动设置。

浏览器打开：

```text
http://127.0.0.1:8008/frontend/login.html
```

接口文档：

```text
http://127.0.0.1:8008/docs
```

## 五、答辩时可以重点说的技术点

### 1. 后端接口

```text
后端使用 FastAPI，实现 RESTful API。前端通过 Axios 调用接口，完成登录、CRUD、审批、查询、统计和导出。
```

### 2. 数据库设计

```text
数据库使用 SQLite，包含用户、角色、温控设备、测点、参数变更申请、审批记录、变更日志、温度读数、报警事件等表。
```

### 3. 软删除

```text
所有业务表都有 deleted_at 字段。删除数据时不是物理删除，而是写入删除时间，方便保留历史。
```

### 4. 审批闭环

```text
参数变更申请提交后进入待审批状态，管理员审批通过后生成审批记录和变更日志，并更新设备参数。
```

### 5. 可视化

```text
前端使用 ECharts 展示温度趋势与偏差、审批状态环图、设备偏差风险排行、参数变更次数、审批优先级矩阵和异常时间分布，并支持导出 PNG。
```

### 6. 数据分析

```text
Notebook 使用 Pandas 读取 SQLite 数据，进行统计分析、异常检测和趋势分析，并用 Matplotlib 输出图表。
```

### 7. 数据导出

```text
系统支持设备、测点、温度记录的 Excel 导出，也支持模板下载、Excel 导入和分析报告 CSV 导出。
```

## 六、常见问题处理

### 1. 提示端口 8008 被占用

说明项目已经启动过了。可以直接打开：

```text
http://127.0.0.1:8008/frontend/login.html
```

如果必须重启，执行：

```powershell
Get-NetTCPConnection -LocalPort 8008 -State Listen | Select-Object OwningProcess
Stop-Process -Id 进程号 -Force
```

然后重新启动：

```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8008
```

### 2. 提示缺少 openpyxl、fastapi、uvicorn 等依赖

执行：

```powershell
cd "<项目根目录>"
python -m pip install -r requirements.txt
```

### 3. 页面打开但接口没反应

先确认 FastAPI 是否运行：

```text
http://127.0.0.1:8008/api/health
```

正常返回：

```json
{"status":"ok"}
```

### 4. 登录失败

先运行造数脚本恢复初始账号：

```powershell
python scripts\seed_data.py
```

再用：

```text
admin / admin123
```
