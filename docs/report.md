# 温控设备参数变更审批系统报告摘要

正式报告见根目录 `作业报告.docx`。

本项目围绕温控设备参数变更审批业务展开，主线为设备建档、测点维护、参数变更申请、管理员审批、审批记录生成、参数变更日志追溯、温度读数查询和数据分析。系统使用 FastAPI 提供 REST API，SQLite 保存业务数据，前端使用原生 HTML/CSS/JS、Axios 和 ECharts，Notebook 使用 Pandas 与 Matplotlib 完成统计分析。

报告正文包含项目背景、需求分析、系统架构、数据库设计、核心功能、数据分析、测试验证和总结。数据库包含系统表与 7 张业务表，所有表包含 `id`、`created_at`、`updated_at`、`deleted_at`，核心业务数据超过 1000 条。
